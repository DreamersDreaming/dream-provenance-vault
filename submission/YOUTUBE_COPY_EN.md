## Title

Dream Provenance Vault — Genblaze + Backblaze B2 Demo

## Description

Dream Provenance Vault creates privacy-safe integrity receipts for exported AI
Dream Cards.

The app verifies a two-step Genblaze Core media lineage, independently checks
the card's SHA-256 in the browser and on the server, and then stores the exact
card, privacy-redacted Genblaze manifest, and application receipt in a private
Backblaze B2 bucket. Proof pages retrieve the private image through a
short-lived signed B2 URL.

Working app:
https://doream-provenance-vault.netlify.app

Verified production proof shown in the video:
https://doream-provenance-vault.netlify.app/proof/213fadb4-117a-4014-91e7-142cf3e93c07

Source code:
https://github.com/DreamersDreaming/dream-provenance-vault

Built for the Backblaze Generative Media Hackathon: Build with Genblaze on B2.

This prototype records file integrity and storage provenance. It does not claim
copyright ownership or store private dream narratives.
