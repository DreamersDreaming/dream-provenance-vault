# Demo Video Script — target 2:20

Use English captions for every spoken line. A generated English narration is
acceptable if the event rules allow it; no live English presentation is
required by this script.

## 0:00–0:18 — Problem

**Screen:** Hero and synthetic Dream Card.

**Narration:**  
“Generative images are easy to copy, but their production evidence is easy to
lose. Dream Provenance Vault preserves a verifiable media lineage without
storing the private dream story behind the image.”

## 0:18–0:42 — Product boundary

**Screen:** Scroll to the disclosure.

**Narration:**  
“This prototype records integrity and storage provenance. It does not claim
copyright ownership. It never asks for dream text, interpretation, identity,
address, or a private prompt.”

## 0:42–1:12 — Genblaze verification

**Screen:** Press “Use synthetic sample.” Show local SHA-256, “Verified / 2
steps,” and the canonical hash.

**Narration:**  
“The bundled synthetic sample includes a real Genblaze Core manifest. It records
two steps: Doream image generation and Doream Prism Card rendering. The private
source prompt is redacted, and the final Genblaze asset hash must match the
selected card exactly.”

## 1:12–1:43 — Backblaze B2 write

**Screen:** Check consent and press “Create B2 proof.” Show the confirmed
receipt.

**Narration:**  
“The browser fingerprints the file first. The server independently repeats the
SHA-256 and Genblaze checks. Only then does it write three objects to a private
Backblaze B2 bucket: the image, the Genblaze canonical manifest, and the app
receipt.”

## 1:43–2:05 — Retrieval

**Screen:** Open the proof receipt and show the signed image, hashes, timestamp,
and Genblaze step count.

**Narration:**  
“The random proof URL retrieves the private receipt. The image is served with a
short-lived signed B2 URL, while the page shows the server hash and Genblaze
canonical hash.”

## 2:05–2:20 — Close

**Screen:** Return to the boundary section, then project name.

**Narration:**  
“Genblaze explains the generative pipeline. Backblaze B2 preserves the exact
artifact and its evidence together. Dream Provenance Vault makes that narrow
claim visible, testable, and privacy-safe.”
